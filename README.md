# 弦上 · String Notes

通过 Keaton Simons 的《Currently》现场演奏，结合音乐分析与六弦指板学习和弦、根音走向、节奏及创作变化。

- 完整演奏约 4 分 7 秒，分为 11 个段落；练习时间线覆盖 130 处事件。
- 121 处和弦提供教学按法；其余事件明确标注旋律、待定或余音。
- 支持按段落选择、播放跟随、速度调整、单和弦及段落循环，以及音名、音程、指号显示。
- Solo 练习是教学改写；页面区分音轨信息、算法候选、教学建议与待核对内容，并非演奏者原指法的逐音定稿。

## 运行与托管

这是纯静态网站，无需安装依赖或构建。主页为仓库根目录的 `index.html`，媒体位于 `assets/`，资源使用相对路径，适合 GitHub Pages 项目站点。

在仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/(root)`。`.nojekyll` 用于直接发布静态文件。
